# Routes

The router (src/router) reads the hash: `#/path?key=value`. Hash routes work on every static host without rules.

| Area    | Routes                                                                                          |
|---------|-------------------------------------------------------------------------------------------------|
| Public  | `#/` `#/about` `#/mission` `#/vision` `#/strategies` `#/staff` `#/partners` `#/thanks` `#/contact` |
